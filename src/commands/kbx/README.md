# KBX Commands

These command wrappers represent the current KBX-facing command taxonomy.

Use this bucket for commands that are primarily about:

- KBX workspace lifecycle
- KBX content/init/update flows
- KBX-specific ontology or release behavior
- downstream-like project operations

This does not mean the underlying implementation is fully clean yet. It means
the intended ownership is KBX rather than neutral SVFactory core.
